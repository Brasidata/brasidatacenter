1. Overview

BrasidataCenter publishes domain ontologies as small, composable modules. Each module defines semantic types, relations and, when available, facade contracts for applications that need a stable public projection of ontology-backed data.

The ontology files are authoritative. This page is a human-readable index and does not replace the Turtle sources.

5. Usage

Importing a module

@prefix ea: <http://datacenter.app.br/ontology/productivity/entity/enrichment_annotation/type.ttl#> .
@prefix schema: <https://schema.org/> .

:issue-001 a ea:IssueAnnotation ;
    schema:name "Resolve document inconsistency"@en .

Using a facade

<http://example.org/my-ontology>
    owl:imports
        <http://datacenter.app.br/ontology/productivity/entity/enrichment_annotation/facade.ttl> .
